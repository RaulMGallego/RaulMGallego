
# ¡Hola! Soy Raúl Murillo Gallego 👋💻

Profesor de Formación Profesional y apasionado del desarrollo de software, la inteligencia artificial y la innovación tecnológica.

En este repositorio comparto materiales, ejemplos, ejercicios, prácticas y recursos educativos utilizados en los módulos del ciclo formativo de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

## 🎯 Objetivos de este repositorio

Este espacio tiene como finalidad:

- Compartir contenidos y recursos didácticos para estudiantes de DAM.
- Facilitar el aprendizaje mediante ejemplos prácticos y proyectos reales.
- Fomentar las buenas prácticas de programación y diseño de software.
- Servir como punto de apoyo para el trabajo en el aula y el aprendizaje autónomo.

## 🚀 Áreas de interés

- Desarrollo de aplicaciones multiplataforma
- Programación en Java
- Bases de datos
- Desarrollo web
- Python
- Inteligencia Artificial y Machine Learning
- Visión por computador
- Cloud Computing y DevOps

Aquí podrás encontrar:
